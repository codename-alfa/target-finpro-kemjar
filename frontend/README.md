# FinVault Next.js Frontend

Frontend aplikasi FinVault Portal yang dibangun menggunakan **Next.js (App Router)** dan **Tailwind CSS**. Frontend ini mereplikasi seluruh antarmuka dan alur pengujian dari folder `/public` untuk target pentest Topic B20 (*No API Authentication and Insecure Change Password Feature*).

---

## Run Frontend

Jalankan command berikut di dalam direktori `frontend`:

```bash
# Masuk ke folder frontend
cd frontend

# Jalankan server development (port 3000)
npm run dev

# Atau build untuk production
npm run build
npm start

# Cek linting
npm run lint
```
